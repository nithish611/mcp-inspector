Notebook Tab Layout

How should cells, args, and results be arranged within the Notebooks tab?

A

Vertical Stack (Jupyter-style)

Cells stacked vertically, each cell is a self-contained block with tool selector, args editor, execute button, and collapsible result — all inline. Scroll to navigate. Simple, familiar to anyone who's used a notebook.

B

Split Panel (IDE-style)

Left panel: cell list (compact, like tool list). Right panel: selected cell's args editor + result (reuses exact same layout as current ToolsTab execution panel). Feels like the existing Tools tab but with a cell list instead of a tool list.

Pros

  • Directly reuses ToolsTab's args+results panel layout
  • More screen space for the active cell's editor
  • Consistent with existing Inspector UX patterns

Cons

  • Can only see one cell at a time in detail
  • Less "notebook" feel — more like "cell picker"
