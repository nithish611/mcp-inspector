Where do notebooks live in the UI?

Both options reuse the existing layout — the question is navigation placement

A

New Tab — "Notebooks" tab next to Tools/Resources/Prompts/Logs

Notebooks are always scoped to the active server in the sidebar. Switching servers switches which notebooks you see. The notebook editor replaces the tools panel layout (tool list + args + results becomes cell list + cell editor + cell results).

Pros

  • Zero sidebar changes — just add a tab
  • Server context is implicit (active server)
  • Familiar navigation pattern

Cons

  • Notebooks tied to one server at a time
  • Can't see tools list and notebook side by side
B

Sidebar Section — Notebooks listed below server list

A collapsible "Notebooks" section appears in the left sidebar under servers. Clicking a notebook replaces the entire tab area with the notebook editor. Clicking a server switches back to Inspector tabs. Notebooks reference a server but aren't nested under one.

Pros

  • Notebooks are first-class objects, not per-server
  • Can reference any connected server
  • Natural "workspace" feel

Cons

  • Sidebar gets more crowded
  • Need to handle server-ref resolution in notebook
  • Slightly more layout work
